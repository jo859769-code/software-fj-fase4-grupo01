# Publicación del proyecto en GitHub

1. Ingresar a GitHub con la cuenta personal.
2. Abrir el repositorio grupal indicado por el curso. Si aún no existe, confirmar primero con el equipo/tutor si debe crearse el repositorio compartido `software-fj-fase4-grupo01`.
3. Verificar que el repositorio esté configurado como **Public** para que el tutor pueda revisarlo.
4. Cargar el contenido de esta carpeta conservando la estructura `models/`, `services/`, `exceptions/`, `utils/`, `tests/`, `docs/` y `logs/`.
5. No subir carpetas `__pycache__`, entornos virtuales ni archivos personales.
6. Realizar commits con mensajes que describan únicamente los cambios propios.
7. Abrir el repositorio en una ventana privada del navegador y comprobar que README y archivos se visualizan sin iniciar sesión.
8. Copiar la URL real del repositorio y pegarla en el apartado correspondiente del informe PDF.

**Importante:** no se puede fabricar ni sustituir la URL real del repositorio. No registrar colaboradores ficticios ni commits de otras personas.
